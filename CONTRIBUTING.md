# Contributing

This repository is a portfolio API backend. External pull requests are not accepted by default.
Automated dependency update pull requests are created by Renovate or Dependabot and reviewed by the repository owner.
GitHub Actions and workflow dependency updates are reviewed manually.

Before opening an issue, read [DISCLAIMER.md](DISCLAIMER.md). The data returned by this API is fictional and must not be used for medical decisions, diagnosis, treatment, or clinical practice.

Do not include secrets, credentials, tokens, private URLs, personal local paths, personal email addresses, private medical information, or vulnerability details in issues, pull requests, comments, commits, logs, screenshots, or fixtures.

Security vulnerabilities must be reported through GitHub private vulnerability reporting. Do not disclose them in public issues.
